# URL Shortener

## Overview
A simple Spring Boot URL shortener that stores mappings in H2 and redirects short codes to their original URLs.

## Tech Stack
- Spring Boot 3.3.2
- Spring Web
- Spring Data JPA
- H2 Database
- Spring Validation
- Java 17

## Setup
1. Clone the project.
2. Ensure you have Java 17 or later installed.
3. Run the app with:
   ```bash
   ./gradlew bootRun
   ```
4. Run tests with:
   ```bash
   ./gradlew test
   ```
5. The app uses a file-based H2 database at `./data/urlshortner`. This directory is automatically created on first run and recreated fresh if deleted.
6. Open the H2 console at `http://localhost:8080/h2-console`.

## API Endpoints
### POST /shorten
Creates a short URL mapping.

Request:
```json
{
  "originalUrl": "https://example.com",
  "customAlias": "my-link"
}
```

Response:
```json
{
  "shortCode": "my-link"
}
```

Use the exact value returned in `shortCode` for the redirect request.

### GET /{code}
Redirects to the original URL for the given short code.

Example:
```bash
GET /my-link
```

## Design Decisions
- Base62 is used for compact, URL-safe short codes.
- Duplicate URLs return the existing short code instead of creating a new mapping.
- Custom aliases are rejected if they already exist.
- Invalid or empty URLs return HTTP 400.
- Redirects use HTTP 301 (Moved Permanently) to indicate permanent redirects.

## Collision Resistance
Short codes are generated by Base62-encoding the database's auto-incremented primary key. Since the database guarantees each URL mapping receives a unique ID, and Base62 encoding is deterministic (same ID always produces the same code), collisions are mathematically impossible without modifying the database itself. Custom aliases are validated for uniqueness before insertion.

## Known Trade-offs
Sequential auto-increment IDs make short codes enumerable and guessable—someone could attempt to access `/1`, `/2`, `/3`, etc. This is an accepted trade-off for simplicity and deterministic collision resistance; if unguessability is required, a future version could use random short codes or UUID-based approaches.
